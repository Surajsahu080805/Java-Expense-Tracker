# Java Expense Tracker

A simple command-line Expense Tracker written in Java. This project demonstrates basic Java programming concepts such as file I/O, collections, and object-oriented design to track expenses and categories.

## Features

- Add, list, and remove expense entries
- Categorize expenses
- Simple persistent storage (file-based)
- Single-file, easy-to-run example for learning and experimentation

## Project Structure

- `src/ExpenseTrackerApp.java` — Main application source file

## Requirements

- Java 8 or newer

## Build & Run (PowerShell)

Open PowerShell in the project root and run:

Compile:

javac -d out src/ExpenseTrackerApp.java

Run:

java -cp out ExpenseTrackerApp

(If `ExpenseTrackerApp` is in a package, adjust the commands accordingly.)

## Usage

Run the application and follow the command-line prompts to add, view, and remove expenses. The app uses a simple text file to persist data between runs.
